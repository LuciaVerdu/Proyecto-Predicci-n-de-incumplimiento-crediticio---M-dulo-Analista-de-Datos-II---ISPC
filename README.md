## Descripción del proyecto

Prueba de concepto (PoC) que evalúa cómo un modelo de regresión logística
puede ayudar a una entidad financiera a identificar clientes con mayor
probabilidad de incumplir sus obligaciones crediticias, utilizando el
dataset Home Credit Default Risk (Kaggle).

## Estado actual: Evidencia 1

de datos (EDA).
